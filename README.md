# ChatGPT در برابر Claude — موشن‌گرافیک فارسی

ویدیوی ۶۲ ثانیه‌ای، ۱۶:۹، ۱۹۲۰×۱۰۸۰، ۳۰ فریم بر ثانیه. همه‌ی متن‌ها فارسی است و موسیقی آن یک قطعه‌ی **اصلِ** ایرانی است که برای همین ویدیو ساخته شده:
دستگاه شور روی «ر» (با «می کُرن»)، ریتم ۶/۸، سنتور با «ریز»، تنبک (تُم و بَک)، زنگ‌های دف و واخوان تنبور.

**فایل نهایی:** `chatgpt_vs_claude.mp4` (H.264 + AAC)

| زمان | صحنه |
|---|---|
| ۰ تا ۶ ثانیه | «نبرد غول‌های هوش مصنوعی» — دو نیمه‌ی سبز و نارنجی، ضربه‌ی «در برابر» |
| ۶ تا ۱۲ | مبارز اول: ChatGPT (سازنده OpenAI، عرضه آذر ۱۴۰۱) |
| ۱۲ تا ۱۸ | مبارز دوم: Claude (سازنده Anthropic، عرضه اسفند ۱۴۰۱) |
| ۱۸ تا ۴۸ | پنج راند: برنامه‌نویسی، نوشتن، تصویر و صدا، اکوسیستم، ایمنی — با نشانگر طناب‌کشی |
| ۴۸ تا ۵۵ | جمع‌بندی: کدام را کِی انتخاب کنیم |
| ۵۵ تا ۶۲ | «انتخاب با شماست!» |

## ساخت دوباره
```bash
node audio.js    # -> soundtrack.wav
node render.js   # -> chatgpt_vs_claude.mp4 (Chromium بدون رابط + ffmpeg)
```
پیش‌نمایش زنده: `index.html` را با یک سرور محلی باز کنید (مثلاً `npx serve .`).
فونت‌ها: Lalezar و Vazirmatn (مجوز OFL).
